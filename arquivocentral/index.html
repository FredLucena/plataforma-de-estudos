O ARQUIVO CENTRAL

Um jogo de quebra-cabeças em 3D para aprender SQL

Você acorda numa instalação científica abandonada. A Inteligência Central — o ARQUIVO — controla portas, elevadores e sistemas de segurança, mas seu banco de dados foi corrompido. Para atravessar os setores, consulte as tabelas nos terminais e escreva o SELECT certo: quando o resultado bate, a porta se abre.
