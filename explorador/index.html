Escolha a pasta deste programa

Selecione a pasta onde explorador.html está salvo, ou arraste-a para esta área. O navegador guarda a escolha para este arquivo: nas próximas vezes a página já abre posicionada nela.

Se o navegador recusar a pasta por ter "arquivos do sistema" (como Downloads, Documentos ou Área de Trabalho), escolha uma subpasta.

Tudo acontece no seu navegador: nenhum arquivo é enviado para a internet.
